# Visual Timer

남은 시간이 부채꼴로 줄어드는 Windows용 시각 타이머입니다. 다이얼을 드래그해서 1~60분을 설정하고, 가운데 노브나 하단 버튼으로 시작과 일시정지를 합니다.

자세한 설계와 입력 규칙은 [기술명세서.md](./기술명세서.md)를 참고하세요.

## 주요 기능

- 다이얼 드래그로 1~60분 설정 (Shift를 누르면 5분 단위)
- 12시가 0분이고 시계 방향으로 증가 (3시 = 15분, 6시 = 30분, 9시 = 45분)
- 시작 시 바늘이 설정 위치에서 출발해 12시 쪽으로 줄어듦
- 하단 시간 표시 버튼, 가운데 노브, Space 키로 시작·일시정지
- R 키 또는 우클릭으로 리셋, T 키로 항상 위 토글
- 종료 시 소리, 화면 깜빡임, 작업 표시줄 깜빡임
- 바깥 테두리를 드래그해서 창 이동

## 기술 구성

| 영역 | 구성 |
| --- | --- |
| 셸 | Tauri 2 (Rust) |
| 프론트엔드 | HTML, CSS, JavaScript (ES 모듈, SVG 다이얼) |
| 시간 계산 | `src/timer-logic.js` (DOM 없는 순수 함수) |
| 테스트 | Vitest 3.2.4 |
| 저장 | 웹뷰 localStorage (`vt-settings`) |

타이머 상태는 종료 시각(`endAt`)을 기준으로 계산합니다. 탭 전환이나 렌더링 지연이 있어도 오차가 쌓이지 않습니다.

## 요구 환경

- Windows 10 1809 이상, Windows 11
- Node.js 22 (`.nvmrc`), npm
- Rust (rustup, stable)
- Visual Studio Build Tools (C++ 데스크톱 개발 워크로드)
- WebView2 런타임 (보통 기본 설치)

## 설치 및 개발 실행

```bash
npm install
npx tauri icon app-icon.png   # 최초 1회: src-tauri/icons 생성 (1024×1024 PNG 권장)
npx tauri dev
```

## 검사 및 빌드

```bash
npm test                      # 시간 계산 단위 테스트
npx tauri build               # NSIS 설치 파일 생성
```

## 사용법

- 정지 상태에서 다이얼 안쪽을 드래그해서 시간을 설정합니다.
- 가운데 노브, 하단 `▶ 시간` 버튼, 또는 Space 키로 시작합니다. 실행 중에 다시 누르면 일시정지합니다.
- 실행 중에는 다이얼로 시간을 바꿀 수 없습니다. R 키로 리셋한 뒤 설정하세요.
- 바깥 테두리를 드래그하면 창이 움직입니다.

## 검증 상태

- 시간 계산 단위 테스트 10개 통과 (`npm test`, Node 22.22.0)
- 개발 빌드(`npx tauri dev`) 실행 확인
- 다이얼 설정, 시작·일시정지, 하단 버튼, 색상 변경 확인

수동 확인이 필요한 항목:
- 종료 시 소리, 화면 깜빡임, 작업 표시줄 깜빡임
- 바깥 테두리 드래그로 창 이동
- T 키 항상 위 토글
- NSIS 설치 파일(`npx tauri build`) 생성 및 설치 후 실행
